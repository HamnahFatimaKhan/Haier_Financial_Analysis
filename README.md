# Haier Financial Statement Analysis (2021–2024)

Business Finance course project analyzing Haier's financial performance over four years (2021–2024) using ratio analysis.

## Overview

This project calculates and interprets five categories of financial ratios from Haier's financial statements, then translates the numbers into plain-language insights and practical recommendations.

## Ratio Categories Covered

| Category | Ratios |
|---|---|
| **Liquidity** | Current Ratio, Acid-Test (Quick) Ratio |
| **Leverage** | Debt-to-Equity, Debt-to-Total Assets, Total Capitalization |
| **Coverage** | Interest Coverage Ratio |
| **Activity** | Receivable Turnover, Payable Turnover, Inventory Turnover, Total Asset Turnover |
| **Profitability** | Gross Profit Margin, Net Profit Margin, Return on Investment (ROI), Return on Equity (ROE) |

## Key Findings

- **Liquidity** stayed close to break-even (Current Ratio ~1.0–1.12), with a slight dip by 2024.
- **Leverage** was moderate and fairly stable, settling around 1.5x Debt-to-Equity.
- **Interest coverage** fell steadily from 23.3x (2021) to 9.4x (2024) — still safe, but the cushion is shrinking.
- **Efficiency** softened slightly: receivable and asset turnover both declined a bit by 2024.
- **Profitability** improved overall — Net Profit Margin rose from 5.8% to 6.8%, and ROE rose from 16.5% to 17.6%.

## Methodology

1. Extracted financial data (2021–2024) from Haier's published financial statements.
2. Calculated liquidity, leverage, coverage, activity, and profitability ratios for each year.
3. Analyzed year-over-year trends for each ratio category.
4. Translated the trends into plain-language commentary and actionable recommendations.

## Recommendations Summary

- Improve short-term liquidity and the acid-test ratio by holding more ready cash and trimming excess inventory.
- Keep debt at a manageable level and pay it down gradually using profits.
- Strengthen interest coverage by growing earnings or lowering borrowing costs.
- Speed up receivables collection and improve inventory forecasting.
- Use assets more efficiently and control production costs to protect margins.
- Keep investing in product quality, innovation, and customer service to sustain profit growth.
